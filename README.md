# Hearth & Hoard

One-page site for Hearth & Hoard, a board game, D&D and slab-pizza tavern at 37 Broadway St E, Yorkton, SK.

Static HTML and CSS with no build step. Hosted on GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).

Before launch, fill in the placeholders in `index.html`: `[EMAIL]`, `[PHONE]`, `[instagram]`, `[hours to confirm]`, `[$]` prices and `[season]`.
